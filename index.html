HybridCache.Plus

Version 1.0.1 • .NET 10 / LTS • Native AOT

High-performance declarative C# source generator extension for Microsoft.Extensions.Caching.HybridCache. Eliminates reflection and runtime emit while providing typed caching contracts, zero-allocation span formatting, and automated cache eviction decorators.

Package Manager Install:
dotnet add package HybridCache.Plus
Ecosystem Modules:
  • HybridCache.Plus.Backplane.Redis: Multi-instance L1 cache invalidation via Redis Pub/Sub channels.
  • HybridCache.Plus.Tenancy.Redis: Multi-tenant dynamic Redis L2 routing with anti-stampede concurrency protection.
  • Source Generators: Compile-time proxy and decorator generation compatible with Native AOT trimming.
View on NuGet GitHub Repository

BetterRedsys

Version 1.0.0 • ASP.NET Core • Native AOT

Modern, strongly-typed, high-performance library for Redsys and Bizum payment gateways in ASP.NET Core. Designed for clean decoupled architectures (React, Next.js, Blazor, Mobile) with strict parameter validation and HMAC-SHA256 signature verification.

Package Manager Install:
dotnet add package BetterRedsys
Ecosystem Modules:
  • BetterRedsys.Simulator: Interactive in-memory sandbox and mock server for local development without ngrok or real bank credentials.
  • Native Bizum Handling: Direct phone authorization flows and asynchronous notification handling.
  • Zero-Reflection Serialization: Built for Native AOT and high-concurrency checkout backends.

LiteTask for Unity

Available on Asset Store
Zero-GC Task Scheduler, Micro-Tweens & High-Precision LiteStopwatch
View in Unity Asset Store

Replaces traditional Unity coroutines and allocations with a high-performance struct pool injected directly into the native UnityEngine.LowLevel.PlayerLoop (Update, FixedUpdate, LateUpdate). Guarantees 0 Bytes GC allocation per frame while offering complete async/await integration, automatic GameObject lifecycle binding via .BindTo(this), and a dedicated in-editor diagnostic monitor.

0 Bytes GC per Frame

Contiguous struct pool eliminates heap allocations and boxing overhead.

Native PlayerLoop Injection

Executes cleanly in engine loop phases without hidden dummy GameObjects.

Built-in Micro-Tweening

15+ easing curves for ultra-smooth animations with zero third-party dependencies.

Editor Visual Monitor

Real-time pool telemetry via Window > Analysis > LiteTask Monitor.

CODE SAMPLES

Implementation Examples

Clean, strongly-typed code patterns across .NET and Unity. 

using HybridCache.Plus;
using Microsoft.Extensions.Caching.Hybrid;

// Declarative interface: C# Source Generator generates caching decorators at compile time
public interface IUserRepository
{
    [HybridCached(Key = "user:{userId}", ExpirationSeconds = 300, LocalCacheExpirationSeconds = 60)]
    ValueTask<UserProfile> GetByIdAsync(Guid userId, CancellationToken ct = default);

    [HybridEvict(Key = "user:{profile.Id}")]
    ValueTask UpdateProfileAsync(UserProfile profile, CancellationToken ct = default);
}

// Registration with Redis L1 backplane (Program.cs):
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddHybridCache();
builder.Services.AddHybridCachePlusBackplaneRedis(options => 
{
    options.Configuration = builder.Configuration.GetConnectionString("redis");
});
using BetterRedsys;
using BetterRedsys.Models;

// Native AOT payment endpoint in ASP.NET Core
var builder = WebApplication.CreateSlimBuilder(args);
builder.Services.AddBetterRedsys(builder.Configuration.GetSection("Redsys"));

var app = builder.Build();

app.MapPost("/api/checkout", (IRedsysClient redsys, OrderRequest req) =>
{
    var payment = redsys.CreatePaymentParameters(new PaymentOrder
    {
        OrderNumber = req.OrderId,
        AmountInCents = req.AmountCents,
        Currency = RedsysCurrency.EUR,
        TransactionType = TransactionType.Authorisation,
        PaymentMethod = PaymentMethod.BizumOrCard
    });

    return Results.Ok(payment);
});
using UnityEngine;
using SoftLake.LiteTask;
using SoftLake.LiteTask.Easing;

// Zero-allocation task scheduling and tweening in Unity
public class EntityController : MonoBehaviour
{
    private void TriggerAction()
    {
        // 0 Bytes GC: Contiguous struct pool in PlayerLoop tied to GameObject lifecycle
        LiteTask.Delay(1.5f, () => ExecuteTask()).BindTo(this);

        LiteTask.Tween(
            from: 1.0f, 
            to: 1.3f, 
            duration: 0.3f, 
            onUpdate: v => transform.localScale = Vector3.one * v,
            ease: EaseType.OutQuad
        ).BindTo(this);
    }
}
