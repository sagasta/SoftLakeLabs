# Soft Lake Labs — Official Website

> **Custom Software Development & High-Performance Systems**

Official website for **Soft Lake Labs**, an independent software engineering studio specializing in custom enterprise software development, distributed high-throughput backends in .NET, published open-source libraries on NuGet, and zero-allocation runtime tools for Unity.

---

## 📦 Published Open Source & Products

### Published NuGet Packages
- **[HybridCache.Plus](https://www.nuget.org/packages/HybridCache.Plus)** (NuGet): Declarative C# Source Generator caching extension for `Microsoft.Extensions.Caching.HybridCache` in .NET with Native AOT support, Redis L1 backplane synchronization, and multi-tenant Redis L2 routing.
- **[BetterRedsys](https://www.nuget.org/packages/BetterRedsys)** (NuGet): Strongly-typed, Native AOT library for Redsys & Bizum payment gateways in ASP.NET Core, bundled with an interactive in-memory simulator (`BetterRedsys.Simulator`).

### Unity Runtime Tools & Systems
- **LiteTask for Unity** (Available on Unity Asset Store): Zero-allocation PlayerLoop task scheduler, micro-tweens, and precision stopwatches (0 Bytes GC per frame).
- **LiteHaptics** (Upcoming): Cross-platform HD haptic feedback engine (iOS CoreHaptics, Android VibrationEffect, Gamepads).
- **LiteSave** (Upcoming): Ultra-fast binary save and state serialization engine.
- **LiteSettings** (Upcoming): Decoupled reactive game configuration manager.
- **LiteMap** (Upcoming): Cache-friendly 2D/3D spatial indexing and grid partitioning.

## 🚀 GitHub Pages Deployment

This static site is optimized to deploy directly on **GitHub Pages**:

1. In your GitHub repository, go to **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment > Source**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save changes.
